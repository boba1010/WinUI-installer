# WinUI installer

- A generic installer built using WinUI 3 for modern and native UI.
- To use it you strictly need a app.zip file that has the files directly not in a subfolder so when the installer extracts it-it finds the files directly not in a /filename/appbinary
- You can edit the InstallerPrepareAPI class and insert your app name and app exe name.
- It is recommended to not change anything else.
- You can replace the app.zip inside Embedded folder with your own app.zip
